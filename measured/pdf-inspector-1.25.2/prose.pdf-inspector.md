# Reading a garden estimate

Case C: prose with aligned text and repeated numbers; no table exists

A list of familiar numbers is not proof that a table survived conversion. The estimate mentions Cedar mulch at 64.00 dollars per cubic metre. It also mentions Screened compost at 88.00 dollars per cubic metre. River gravel is priced at 145.00 dollars per cubic metre in this example. These are independent sentences in a paragraph, not cells in a grid. A checker must not infer a table merely because all three values occur.

## What should remain true

The prose stays prose. Material names retain their own prices. A missing table is different from a table with a wrong cell. Review the source before trusting a tidy-looking Markdown preview.
